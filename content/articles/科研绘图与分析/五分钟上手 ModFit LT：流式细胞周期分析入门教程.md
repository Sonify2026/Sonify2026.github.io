在做流式细胞术分析时，很多人最头疼的不是实验本身，而是如何 **快速、准确、自动** 地处理一堆 FCS 文件。ModFit LT 作为 DNA 含量和细胞周期分析的经典软件，常常被认为“难上手”。其实，它比你想象中更简单！

这篇推文将带你从零开始，把官方教程中最核心、最实用的操作流程全部拆解出来：如何创建项目、导入数据、自动分析、生成 PDF 报告、建立数据库……  

只要跟着做一遍，你就能轻松掌握 ModFit LT 的完整使用流程。

ModFit LT 的功能区（ribbon bar）位于窗口的最上方。上面的按钮根据功能分组，方便你快速找到和使用软件中最常用的操作。

![[Pasted image 20251115161728.png]]

### 创建一个新项目

在顶部功能区的“Project”区域中，点击“New”按钮即可新建项目。

此时会出现“新建项目（New Project）”的对话框。

• 在“Type（类型）”中选择 _Cell Cycle（细胞周期）_。
• 在“Name（名称）”一栏输入项目的名称，这里我们输入 _Tutorial 1_。
• 点击“More（更多）”按钮，并勾选“Copy Data Files（复制数据文件）”选项。
• 最后点击“OK”确认创建项目。

![[Pasted image 20251115162123.png]]

ModFit LT 会在你的“Documents（文档）”下的 _ModFit LT Projects_ 文件夹中，创建一个名为 **Tutorial 1** 的新文件夹。当你为这个项目选择 FCS 文件时，ModFit LT 会把这些文件复制到项目文件夹里。

### 向项目中添加文件

在我们已经创建好细胞周期（Cell Cycle）项目后，接下来要导入一些 FCS 数据文件。这里我们以软件自带的实例进行演示，实际应用时，可以导入自己的流式数据文件。

• 点击顶部功能区中的 **Open FCS** 按钮，此时会弹出“Open Data（打开数据）”对话框。
• 前往 ModFit LT 的安装位置：
　• **Windows:** Program Files\Verity Software House\ModFit LT 6.0  
　• **MacOS:** Applications\ModFit LT 6.0
• 打开其中的 _Samples（示例数据）_ 文件夹，选择以下四个 DNA 示例文件：  
　- DNA-Sample1.fcs  
　- DNA-Sample2.fcs  
　- DNA-Sample3.fcs  
　- DNA-Sample4.fcs
• 最后点击 **打开**，将这些文件加入到项目中。

![[Pasted image 20251115162621.png]]

### 选择要分析的测量参数并设置门（gate）

当打开第一个文件时，会显示 _Analysis Setup_（分析设置）对话框。  
该对话框允许我们设置一个或多个门（gates），并选择需要进行分析的测量参数。

我们要分析的测量参数已经被正确选中：**FL3 PI**。

<p align="center">
  <img src="Pasted image 20251114165902.png" width="400">
</p>

为了更清晰地观察数据，我们可以添加一个门（gate）。 
• 在当前对话框中点击 **Add Gate（添加门）** 按钮，软件会新增一个门并显示在图上。  
• 点击图中 X 轴的标签 **“FS”**，此时会弹出该 FCS 文件中所有可用测量参数的列表。  
• 在列表中选择 **FL3 PI**，让 X 轴显示 DNA 染料（PI）的信号。

<p align="center">
  <img src="Pasted image 20251114170334.png" width="400">
</p>

点击OK确认。

<p align="center">
  <img src="Pasted image 20251114170452.png" width="400">
</p>

对话框会自动关闭，随后软件开始读取文件。报告页面会显示 DNA 信号（“FL3 PI”）的 **1P 直方图**，同时也会呈现一个 **FL3 PI 与 SS（侧向散射）** 的散点图，用于观察数据分布和门控情况。

在主窗口的左侧，你会看到刚加入的 FCS 文件列表。文件列表下面，会显示与分析相关的各种处理选项，供你进一步调整。

![[Pasted image 20251115163041.png]]

### 选择处理选项

在屏幕左下方的“处理选项”区域，你可以决定 ModFit LT 在分析我们加入的这些 FCS 文件时要执行哪些操作。  
其中 **Type（类型）** 已经设为 _Cell cycle（细胞周期）_，这是我们在创建项目时选定的。  
**Analysis（分析方式）** 也已经设置为 _Auto Analyze（自动分析）_，这正是我们在本教程中希望使用的方式。

现在，我们来启用两个输出选项：
• 在选项列表中勾选 **Save Report（保存报告）** 和 **Save PDF（保存 PDF 文件）**。

![[Pasted image 20251115163246.png]]

在设置了这些选项后，每个文件都会自动进行分析，同时软件会保存一份分析报告，并自动生成对应的 PDF 文件。

### 处理文件

现在我们已经准备好对项目中的文件进行分析了。分析操作可以在主窗口左下角的控制区域完成。
• 点击 **Run（运行）** 按钮，软件就会开始分析列表中的第一个文件。

![[Pasted image 20251115163420.png]]

ModFit 会自动对样本进行分析。它会先扫描直方图，寻找其中的峰值，并根据这些峰的位置和大小，判断样本中包含多少个细胞周期群体。之后，软件会对数据进行一种叫作“非线性最小二乘拟合”的计算方式，以获得更准确的结果。

分析完成后，结果会显示在 DNA 直方图的右侧区域。

![[Pasted image 20251115163526.png]]

我们也可以让软件自动处理列表中剩下的所有文件。
• 点击工具栏上的 **Auto Advance（自动前进）** 按钮即可让软件自动依次分析后续文件。

![[Pasted image 20251115174708.png]]

处理剩下的文件通常不会花太多时间。你会注意到，随着文件一个个被分析，文件列表中会显示出哪些文件已经完成分析。

![[Pasted image 20251115174755.png]]

### 创建数据库

下面我们来使用“数据库向导（Database Wizard）”为这个项目建立一个保存分析结果的数据库。
• 在顶部功能区点击 **Edit（编辑）** 标签页。
在“Database（数据库）”区域中，点击 **Database Wizard（数据库向导）** 按钮。

![[Pasted image 20251115174935.png]]

Database Wizard（数据库向导）的对话框此时会显示出来。
• 点击 **Next（下一步）**。
• 在向导的下一页中，将数据库名称选择为 **“Tutorial 1”**。
• 最后点击 **Finish（完成）** 结束设置。

![[Pasted image 20251115175051.png]]

当向导关闭后，屏幕上会出现一个新的 **Database Viewer（数据库查看器）** 窗口。这个窗口可以让我们在记录被加入数据库时实时查看它们。数据库中的字段（项目）是向导根据刚才的分析内容自动生成的。

因为分析这些文件非常快，我们可以再重新分析一次，这样结果就会被写入到刚刚创建的数据库里。

• 点击批处理工具栏上的 **Choose（选择）** 按钮，然后在菜单中选择 **DNA-Sample1.fcs**。

![[Pasted image 20251115175252.png]]

• 点击 **Auto Advance（自动前进）** 按钮，重新处理项目中的四个文件。

![[Pasted image 20251115174708.png]]

Database Viewer（数据库查看器）窗口中会出现来自这四个文件的四条分析记录，表示这些结果已经成功写入数据库。

![[Pasted image 20251115175406.png]]

> <font color="#de7802">项目数据库</font>
> 当你创建一个新项目时，软件也会为这个项目自动建立一个数据库。通过 **Database Wizard（数据库向导）**，你可以快速为数据库添加需要的字段。你可以选择让数据库查看器窗口显示或隐藏，这不会影响数据库本身。只要数据库处于“激活（active）”状态，文件在分析时产生的记录就会自动加入数据库。
> 
> 在数据库查看器上有一个按钮，可以切换数据库的激活状态：开启或关闭。
> 
> <font color="#de7802">Optional step（可选步骤）</font>
> 为项目创建数据库并不是必须的，但如果你希望将实验结果导出到其他软件（例如 Excel）中进行进一步分析，那么创建数据库会非常有帮助。

### 查看分析结果

现在，我们已经有了一个正常运行的数据库，并且项目中的每个 FCS 文件都应该生成了对应的报告（report）和 PDF 文件。接下来，我们来查看其中一个文件的分析结果。
• 双击列表中的第一个文件，会弹出一个带有多个选项的对话框。
• 选择 **Open Report（打开报告）**。

![[Pasted image 20251115175811.png]]

第一个文件的分析报告会被打开，我们可以查看报告内容，或根据需要对分析进行修改。
• 再次双击列表中的第一个文件，这一次选择 **Open PDF（打开 PDF）**。

该文件对应的 PDF 会在你电脑默认的 PDF 查看器中打开，其内容与 ModFit LT 软件窗口中的报告是一致的。

此外，你也可以通过功能区（ribbon）上 **Home（主页）** 选项卡里的 **Open Report（打开报告）** 按钮来打开报告。

![[Pasted image 20251115175934.png]]

### 重新保存项目

在对项目做出修改后，随时保存项目是一个好习惯。虽然软件会在某些情况下自动保存，但并不是所有操作都会自动保存，所以手动保存仍然很重要。
• 在功能区（ribbon）的 **Home（主页）** 选项卡中，点击 **Project（项目）** 区域里的 **Save（保存）** 按钮。

![[Pasted image 20251115180042.png]]

• 这时会弹出一个对话框，询问你是否要保存更新后的报告模板。请选择 **Yes（是）**。

> <font color="#de7802">报告模板</font>
> 报告模板中保存了与你的分析相关的设置信息，例如：
> - 你选择用于分析的测量通道
> - 所使用的门（gate）
> - 以及你可能加入报告的其他元素
> 
> 每次重新打开这个项目时，ModFit LT 都会自动加载这个报告模板。

### 重新打开项目

现在让我们重新打开项目，确认它已经正确保存。 
• 在功能区（ribbon）的 **Home（主页）** 选项卡中，找到 **Project（项目）** 区域，点击 **Open（打开）**
• 此时会出现 **Select a Project（选择项目）** 对话框，界面中会显示项目所在的 Projects 文件夹。
• 在列表中选择 **Tutorial 1**，然后点击 **选择文件夹** 按钮。

项目将随即打开。你会看到文件列表和之前设置的处理选项都保持原样。数据库查看器也会显示出来。  
报告模板同样会被加载，不过此时 DNA 图和门控图会显示 **“No Data（无数据）”**，这是正常现象。

![[Pasted image 20251115180501.png]]

要查看之前已经分析过的某个报告，只需在文件列表中双击该文件，然后选择 **Open Report（打开报告）**。

你可以随时向项目中继续添加新的文件，以便分析更多的数据。  
你也可以将当前项目 **另存为一个新名称**，这样新的项目会保留与现在项目相同的设置和结构。
