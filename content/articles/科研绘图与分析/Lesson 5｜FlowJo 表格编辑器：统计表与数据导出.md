在 FlowJo 分析流程中，**门控解决的是“看什么”，而统计表解决的是“怎么量”**。很多人已经能够熟练完成 gating，却仍然会在后续阶段遇到这些问题：
- 如何一次性导出所有样本的统计结果？
- 怎样把各类统计指标，整理成可直接用于统计的软件表格？
- 能不能在 FlowJo 里就快速看出哪些样本高、哪些样本低？

这些问题的答案，都集中在 FlowJo 的一个核心模块中——**Table Editor**。

## 表格编辑器概述

**Table Editor（表格编辑器）** 是 FlowJo 中用于 **可视化与导出门控群体统计结果** 的核心平台。与 Layout Editor 类似，表格编辑器也在一个 **独立于工作区的窗口** 中运行。

通过表格编辑器，你可以将从门控群体中计算得到的各种统计量（如频率、MFI、GMFI、事件数等）以表格形式直观查看，并导出为多种外部数据格式，用于后续统计分析或科研发表。

支持的导出格式包括：**Text（文本）**、**CSV**、**Excel**、**SQL 数据库**。

📌 表格编辑器中保存和导出报告的流程，与 Layout Editor 中的 **Batch Reporting** 在逻辑上是高度一致的。

### 表格编辑器的组成

- <font color="#de7802">功能区：</font>Table Editor 拥有独立的功能区。
- <font color="#de7802">Table Editor 标签：</font>用于：添加、复制、删除表格；设置 **迭代方式**；设置输出相关选项
- <font color="#de7802">Edit 标签：</font>用于添加或编辑 **列**；添加 **样本关键词**；设置 **表头和表尾**
- <font color="#de7802">Visualize 标签：</font>用于设置 **热图**；调整表格格式；添加简单的 **可视化图形**

### 操作练习：将群体与统计节点加入表格编辑器并生成表格

下面我们将把门控群体和统计节点引入表格编辑器，并生成一个可视化表格。

1. 在 **工作区窗口的工具栏** 中，点击 **网格状按钮**，打开 **Table Editor**。  
    将 **工作区窗口** 与 **Table Editor 窗口** 并排摆放，便于拖拽操作。

![[FlowJo基础教程（五）-20251216-1.png]]

2. 在工作区中 **单一样本的门控树** 内，选中 **一个或多个门控群体节点和/或统计节点**。
3. 将所选节点 **拖拽并放入 Table Editor**。  
    对于每一个被拖入的节点，Table Editor 中都会生成一行，显示：
    - 该节点在门控层级中的位置
    - 所对应的统计类型（如 Frequency、Median、GMFI 等）
4. 在 **Output（输出工具带）** 中，点击 **Create Table（生成表格）**。  
    表格会在新窗口中显示。

![[FlowJo基础教程（五）-20251216-2.png]]

### 操作练习：在 Table Editor 中重命名一行

在实际分析中，**门控树往往层级较深、名称较长**。为了让表格更简洁、便于后续统计和作图，可以在 **Table Editor 中为某一行指定一个更简短、直观的名称**。

1. 在 **Table Editor** 中，找到你希望重命名的 **单独一行**，并在该行的 **Name（名称）字段** 上 **双击**。
2. 输入一个 **唯一且简洁的名称**  
    （例如：**CD8 %**）。
3. 点击 **Create Table（生成表格）**。  
    系统会生成一个新的表格，其中该行将使用你刚刚指定的名称。

![[FlowJo基础教程（五）-20251216-3.png]]

### 操作练习：为表格输出添加热图显示

为了更直观地观察各项统计指标在不同样本之间的数值变化范围，可以对 Table Editor 的输出表格列应用 **热图** 形式的可视化格式。

1. 在 **Table Editor** 中，选中 **所有统计行**。
2. 在 Table Editor 的功能区中，选择 **Visualize（可视化）** 标签页。
3. 点击 **Heat Map（热图）**。  
    此时，在 Table Editor 中每一条被选中的行，其 **Population** 列中都会出现一个 **火焰图标**，表示该统计项已启用热图显示。

![[FlowJo基础教程（五）-20251216-4.png]]

4. 在功能区中切换回 **Table Editor** 标签页。
5. 点击 **Create Table（生成表格）**。

系统将生成一个新的输出表格。在该表格中，**每一列都会以热图方式显示**： **蓝色** 表示该列中的 **低值**;**黄色** 表示该列中的 **高值**。

![[FlowJo基础教程（五）-20251216-5.png]]

> 💡<font color="#de7802">Heat Map ≠ 定量分析，而是“模式识别”</font>
> 
> Table Editor 中的热图主要用于：
> - 快速发现 **样本间的相对高低**
> - 识别 **趋势、异常值或分组模式**
> - 辅助 QC 与初步探索性分析
> 
> 它并不替代正式的统计检验，而是回答一个问题：**“哪些样本高？哪些样本低？”**

### 操作练习：将表格保存为文本文件

现在我们将把生成的数据表 **导出并保存为 FlowJo 之外的文件**，以便用于后续统计分析或结果存档。

1. 在 **Output（输出工具带）** 中，点击 **Display（显示方式）** 字段。  
    在下拉菜单中选择 **To File（导出为文件）**。  
    此时，其下方的 **File Type（文件类型）** 字段会自动显示为 **Text**，表示在生成表格时将保存为 **文本文件（.txt）**。  
    目前保持默认设置即可。需要注意的是，FlowJo 还支持多种其他导出格式，包括：**CSV**、**Excel**、**HTML**、**SQL 数据库**。

![[FlowJo基础教程（五）-20251216-6.png]]

2. 点击 **Destination（目标位置）** 字段，选择保存文本文件的位置  
    （例如：**桌面**），并点击 **Save（保存）**。
3. 点击 **Create Table（生成表格）**。  
    数据表将被生成并自动保存为一个 **文本文件** 到你指定的位置。

![[FlowJo基础教程（五）-20251216-7.png]]

生成的数据表会被保存到你指定的目标位置，并且可以使用 **任何文本编辑器或电子表格软件** 打开。  
此外，如果你只是想快速转移信息，也可以直接 **从已显示的表格中复制并粘贴文本到电子表格软件** 中。

另外，如果你希望 **保留热图的可视化格式**，建议将表格保存为 **HTML 文件**。HTML 文件会在 **网页浏览器** 中以图像形式打开，并且会 **完整保留所有可视化格式设置**（包括热图配色）。

由于我们目前已经完成了表格的创建与导出操作，现在可以 **关闭所有已打开的 Table Editor 窗口**，以清理界面并继续后续工作。
