学习本篇内容，你将掌握：
- Graph Window 的结构与常见可视化模式
- 使用 FSC/SSC、Histogram、Quadrant 等不同视图识别细胞群体

- 构建完整层级结构
- 分离经典免疫群体，如 **Lymphocytes、Live Cells、CD3+、CD4+、CD8+、Perforin+ CTL**

本篇将理论与实践结合，帮助你从“会画门”走向“理解门控逻辑”，建立可发表级别的流式细胞数据分析结构。

## 图形窗口与门控

### 图形窗口

**图形窗口** 用于展示流式细胞数据文件中的事件（events）在一个或两个检测参数维度上的分布情况，即以图形方式可视化细胞群体结构。这一可视化过程使我们能够观察采集到的细胞（本例中为 **人淋巴细胞 human lymphocytes**）在不同参数下的信号分布特征。

> 💡 **术语说明 — Parameter（参数）**  
> 在流式细胞术中，**参数**通常指仪器在单个通道（channel）上采集的一种荧光脉冲信号或散射光信号。不同参数可用于反映：
> - **蛋白表达水平**（如 CD3、CD4、CD8、PD-1 等免疫表面分子）
> - **细胞大小和内部复杂度**（FSC = forward scatter，SSC = side scatter）
> - **细胞活性或状态指标**（Live/Dead 染料、生物能量代谢染料、ROS、Calcium flux）
> - **DNA含量、细胞周期、膜完整性**

图形窗口提供绘制**几何门（geometric gates）** 的工具，用于定义和分割细胞亚群。当你在数据分布图上绘制一个门时，该门内包含的事件（cells）将被隔离出来，形成一个 **子群体（child population）**，而原始整体数据为 **父群体（parent population）**。

通过在不同参数上连续绘制多个门，可以构建 **Gating Hierarchy（门控层级）** 或 **Gating Tree（门控树）**，逐层筛选目标细胞群体，从而分离更特定的细胞类型。

📌<font color="#de7802">补充说明  — 为什么 Gating 至关重要？</font>

流式细胞术本质上是 **高维单细胞分析技术**，而 gating 是理解与提取生物学信息的核心工具。

<center>典型门控流程示例</center>

|步骤|参数|目的|
|---|---|---|
|1. FSC-A vs SSC-A|选择淋巴细胞群|排除碎片、细胞核、红细胞|
|2. FSC-H vs FSC-A|Single cells（单细胞）|去除双ts或聚集体|
|3. Live/Dead stain|活性判断|只保留活细胞|
|4. CD3|T cells||
|5. CD4 vs CD8|区分 T cell 亚群||
|6. Activation/exhaustion|PD-1、TIM-3、CTLA-4 等|

1. **双击工作区中的第一个样本**：`LD1_NS_NS` （点击样本名称，而不是其左侧的图标。）  
    会打开一个 **Graph Window（图形窗口）**，默认显示基于 **FSC（Forward Scatter，前向散射）** 与 **SSC（Side Scatter，侧向散射）** 参数的事件分布图。

![[FlowJo基础教程（二）-20251205-1.png]]

打开图形窗口后，你会注意到在 Workspace 窗口中，该样本名称旁的 **蓝色菱形 群体标记徽章）** 变成 **实心蓝色**，表示该样本的图像处于当前激活状态。

##### 如何解读 Graph Window 中的散点图？

图中 **每一个点**代表一个或多个单细胞事件，这些事件在流式细胞仪中采集并记录多个参数信号。
- **X 轴（FSC）** 主要反映细胞 **大小（cell size）**
- **Y 轴（SSC）** 反映细胞内部颗粒度或复杂程度（granularity / complexity）

在图中，事件密度使用颜色梯度编码：

|颜色|含义|
|---|---|
|**红色**|高事件密度区域（大量细胞集中）|
|**黄色 – 绿色 – 蓝色**|依次表示逐渐减少的细胞密度|

这种绘图方式也称为 **density dot plot（密度散点图）**，适用于展示 PBMC、肿瘤浸润淋巴细胞（TIL）、骨髓细胞等多群体复杂样本的结构状态。

### 图形窗口的组成部分

- **Gating Tools（门控工具）** 位于窗口左上角，用于绘制各种类型的门（gate），包括多边形门、矩形门、椭圆门、象限（quadrants）、区间门（interval）等。
- **Undo / Redo（撤销 / 重做）和 Navigation（导航切换）按钮** 位于窗口右上角，支持快速调整和管理门控操作步骤。
- **X Axis 与 Y Axis Labels（坐标轴标签）** 指示当前图中展示的参数。  
    **点击任意轴标签**可选择新的参数（如从 FSC 切换到 CD3、CD4、CD8 或其他荧光通道）。
- **Transformation Button（T 按钮）** 位于每个坐标轴标签旁，用于选择数据变换方式和缩放比例，帮助优化信号可视化。
- **Plot & Gate Display Options（绘图与门控显示设置）** 位于窗口底部的可展开栏中，用于修改图像显示风格、标注方式、颜色映射和门控展示模式等。

![[FlowJo基础教程（二）-20251205-2.png]]

📌<font color="#de7802">补充说明 — Transformation（数据变换）按钮（T）</font>

流式数据常使用 **Logicle / Biexponential / Log / Linear / Arcsinh** 等变换方法，使弱表达与强表达信号在图中都可清晰分离。

|变换方式|适用场景|优势|
|---|---|---|
|**Linear**|FSC、SSC|看清细胞大小和颗粒结构|
|**Log**|荧光参数|扩展弱阳性群体|
|**Logicle / Biexponential**|多色补偿后数据|解决负值，可视化最佳|
|**Arcsinh**|CyTOF / Mass cytometry|动态范围极大|

#### 操作练习：绘制椭圆门

接下来，我们通过 **椭圆门** 来圈定本散点图中的主要 **淋巴细胞** 群体。

在当前的 FSC vs SSC 图中，淋巴细胞是占比最高的细胞群，其分布区域密集，表现为 **红色、黄色与绿色** 的高密度区域。我们将对这个主体群体进行门控，以便在后续步骤中进一步细分更小的亚群（如 T cells / B cells / NK cells）。

📌<font color="#de7802">补充说明 — 为什么选择椭圆门？</font>

在流式分析中，绘制门（gating）时通常会根据群体形状选择不同类型的门：

|门类型|常用途|优势|
|---|---|---|
|**Ellipse Gate（椭圆）**|圈定类高斯分布的群体，尤其是 FSC vs SSC 细胞主群|**围绕密集核心区域更加自然，减少包含杂散点**|
|Rectangle Gate（矩形）|粗略选择或快速试验|简单但精度较低|
|Polygon Gate（多边形）|需要精细边界的复杂群体|**最灵活，最常用**|
|Quadrant（象限）|比较两个荧光参数阳性/阴性群体|CD4+/CD8+、PD-1+/TIM-3+ 等|
|Interval（区间门）|单通道筛选强度|MFI cutoff、DNA周期分析|

1. **点击 椭圆门控工具按钮**。
2. 将鼠标移动到希望圈定的细胞群边缘位置。  
    **按住鼠标左键并拖拽**，围绕目标群体绘制一个椭圆形区域，完成后松开鼠标。

![[FlowJo基础教程（二）-20251205-3.png]]

3. 为该门命名（可以手动命名，或使用系统推荐名称 **“Lymphocytes”**）。  
    按 **Enter** 或点击 **OK** 完成命名。

![[FlowJo基础教程（二）-20251205-4.png]]

4. 此时，门已经成功创建并显示在图上。  
    门旁会显示 **Gate 名称** 和一个统计值，称为 **Frequency of Parent（父群百分比）**。
    📌 **Frequency of Parent** = `(门内事件数 / 父群体事件数) × 100%`  
    表示该子群体（child population）占父群体的比例，是最常见的门控统计指标，也为默认显示方式。

![[FlowJo基础教程（二）-20251205-5.png]]

5. 按住鼠标左键拖动 **门名称标签**，可将其移动至更合适的可视位置，以避免遮挡数据。

![[FlowJo基础教程（二）-20251205-6.png]]

6. **点击并按住椭圆门的边界区域（不是标签）**，将其拖动到图中的其他位置，然后松开鼠标。  
    你会看到 **父群百分比** 的数值会随着门的位置移动而更新。

![[FlowJo基础教程（二）-20251205-7.png]]

7. **点击并按住门边缘的方形控制点**，拖动画门的大小或形状，以调整门控范围。

![[FlowJo基础教程（二）-20251205-8.png]]


8. 重复移动和调整门的形状，使其尽可能准确地圈定散点图中最密集的主群体。
9. 当你对门的形状与位置满意后，**双击门内区域**。  
    FlowJo 会打开一个新的 **图形窗口**，显示该门内事件（细胞）的独立 FSC 与 SSC 分布图。

![[FlowJo基础教程（二）-20251205-9.png]]

📌<font color="#de7802">补充说明 — 为什么需要动态调整门控？</font>

在门控分析中，**门的位置与形状直接影响统计结果与生物学解释**。移动门或调整门的边界会改变包含事件的数量，因此：
- **严格贴近密度核心区域**
- **避免采集异常点或 outliers**
- **跨样本保持一致性以确保可比较性**

<center>门控调整过程体现的核心逻辑</center>

|目标|方法|
|---|---|
|精确圈定目标群体|包含密度最高区域，排除噪点|
|避免过度限制|留出自然生物学范围|
|支持跨样本批量应用|建立可重复的结构化门控策略|

<font color="#de7802">🔬 FSC / SSC 主门的重要性</font>

建立 lymphocyte 主门是典型 PBMC 或临床免疫样本中完整 gating strategy 的第一层。  
如果这一层不准确，将直接影响后续：
- Single cells 过滤（FSC-H vs FSC-A）
- Live/Dead 过滤
- T / B / NK / Monocyte 分类
- Activation / exhaustion marker 分析（PD-1、TIM-3、CTLA-4等）

<center>常见错误与影响</center>

|错误|结果|
|---|---|
|门太大|混入 monocytes 或 dead cells，影响 MFI 和%|
|门太小|排除真实淋巴细胞，导致假阴性或组间差异假象|
|样本间不一致|统计不可比，审稿人拒稿重点|

#### 操作练习：使用多边形门分离活细胞

**胺反应染料（Amine Reactive Dyes，ARD）** 是常用的 **活 / 死细胞鉴定染料**。死亡细胞由于其**质膜完整性受损**，染料能够进入细胞并在 ARD 通道中产生高荧光信号；而**活细胞**质膜完整性良好，排斥染料，因此在 ARD 通道中具有**低荧光强度**。

因此，为了分离**活细胞群体**，我们将针对**ARD 低荧光**区域进行门控，并排除**ARD 高荧光**死亡细胞。

##### 操作步骤
1. **在图形窗口中显示 ARD 参数**  
    点击 **Y 轴坐标标签**，在弹出的参数列表中选择：**Comp-AARD-A :: Dead**，此时，Y 轴将展示 **AARD（aqua amine reactive dye）** 的荧光测量值，并区分活与死细胞。

![[FlowJo基础教程（二）-20251205-10.png]]

2. **选择 多边形门工具**。
3. 在图上点击多个位置以创建多边形门的顶点，形成期望形状。  
    可根据需要设置任意多边形边数。  
    📌 提示：**按住 Shift 键** 会将线段角度限制为 **45°倍数**，便于构造规则边界。

![[FlowJo基础教程（二）-20251205-11.png]]

4. **双击关闭 Polygon Gate**，完成门的创建。
5. 为门命名，例如：**“Live”**，然后点击 **OK**。

#### 操作练习：切换为直方图显示；绘制区间门筛选 CD3+ T 细胞

1. **双击“Live”门内区域**，打开一个新的图形窗口，仅显示 **活细胞群体**。
2. 点击 **X 轴参数标签**，在可选参数列表中选择：**Comp-Ax700-A :: CD3**，然后点击 **Y 轴参数标签**，选择 **Histogram（直方图）**。这样图像会切换为 **单参数直方图**，显示 CD3 的荧光表达强度分布。你会注意到左上角可用的门控工具也发生变化，只显示 **Range Gate（区间门）** 和 **Bifurcation Gate** 可选项。

![[FlowJo基础教程（二）-20251205-12.png]]

3. 选择 **Range Gate（区间门）** 工具。
4. 在偏右侧的 **CD3 双峰分布中高峰区域**绘制区间门：  
    在峰的一侧按住鼠标左键拖动至另一侧后松开，形成区间选择。

![[FlowJo基础教程（二）-20251205-13.png]]

5. 为该门命名，例如 **“CD3+”**，然后点击 **OK**。  
    此时，CD3 表达阳性的事件已经被成功隔离。

<font color="#de7802">📌补充说明 — CD3 是什么？为什么这么做？</font>

**CD3 是 T 细胞受体复合体（TCR complex）的核心结构蛋白**，存在于所有成熟 T 细胞表面，因此：

|群体|CD3 表达水平|
|---|---|
|**T 细胞（T cells）**|CD3 高表达（CD3+）|
|**B / NK / Myeloid cells**|CD3 阴性或极低|

在 Live/Dead gate 之后进行 CD3 gating，可以**从所有活细胞中分离出 T 细胞主群体**，为后续 CD4/CD8 进一步分析做好准备。

🔬 <font color="#de7802">为什么用 Histogram（直方图）与 Range Gate？</font>

直方图优点

|优势|说明|
|---|---|
|展示单参数表达水平分布|便于区分阴性 / 阳性群体|
|可清晰观察双峰或拖尾现象|验证染色效果|
|确定阈值 cutoff 更直观|针对表达强度分布做判断|

CD3 分布通常呈双峰，左侧低峰 = **CD3–** 非 T 细胞，右侧高峰 = **CD3+** T cells，区间门可有效将其分离。

#### 操作练习：绘制象限门分离 CD4+ 与 CD8+ T 细胞

现在，让我们进一步将 **CD3+ T 细胞群体**细分为：
- **CD4+ 辅助性 T 细胞（T helper cells）**
- **CD8+ 细胞毒性 T 细胞（cytotoxic T lymphocytes, CTL）**

##### 操作步骤
1. **双击 CD3+ 门**，打开一个新的图形窗口，此窗口只显示 **CD3+ 事件**。将 **X 轴参数**更改为：**Comp-PE-TxRed-A :: CD4**，将 **Y 轴参数**更改为：**Comp-PacBlue-A :: CD8**
2. 选择 **蜘蛛象限门**工具。

![[FlowJo基础教程（二）-20251205-14.png]]

3. 将鼠标光标移动到希望设置象限交点的位置，**点击一次**，四象限门即会出现。  
    至此，你已创建象限门，用于区分 **CD4 vs CD8** 表达群体。
4. 点击象限门边缘任一方形控制点（gate handle），并拖动以更改象限中心位置或调整象限边界角度，以优化群体分离效果。

![[FlowJo基础教程（二）-20251205-15.png]]

🔬<font color="#de7802">象限门的优势</font>

|优点|应用场景|
|---|---|
|同时比较两个标志物的表达关系|CD4 vs CD8、PD-1 vs TIM-3、CD45RA vs CCR7（T cell memory subsets）|
|自动计算四象限占比|群体分布变化最直观|
|支持快速识别双阴/双阳亚群|Exhaustion / activation 分析常用|

🔬<font color="#de7802">使用该象限门后，将可得到：</font>

|象限|群体含义|
|---|---|
|**CD4+ CD8–**|辅助性 T cells|
|**CD4– CD8+**|细胞毒性 T cells|
|**CD4– CD8–**|双阴群（可能是 NK、γδ T 等）|
|**CD4+ CD8+**|双阳 T cells（胸腺来源或激活状态）|

#### 操作练习：绘制矩形门分离 Perforin+ CD8+ 细胞毒性 T 细胞亚群

现在，我们将聚焦于 **CD8+ T 细胞群体**，并进一步圈定其中表达 **Perforin（穿孔素）** 的功能细胞亚群。
1. **双击 Q1: CD4–, CD8+** 这一象限群体，打开一个新的图形窗口，仅显示 **CD8+ T cell**。将 **X 轴参数**更换为：**Comp-PE :: Perforin**
2. 选择 **矩形门控工具**。  
    将鼠标光标放置在希望作为矩形门一角的位置处，**按住左键并对角线方向拖动**，然后松开，即可创建矩形门。
3. 给该门命名，例如：**“Perf+”**，点击 **OK**。  
    至此，你已经成功从 CD8+ 群体中隔离出 **Perforin+ 功能性细胞毒性 T 细胞亚群**。

![[FlowJo基础教程（二）-20251205-16.png]]

📌<font color="#de7802">补充说明 — Perforin 的免疫学意义</font>

**Perforin（穿孔素）** 是 CD8+ 细胞毒性 T 细胞与 NK 细胞用于杀伤靶细胞的重要效应分子，通过形成跨膜孔洞，使 Granzyme B 进入靶细胞引发凋亡。因此，**Perforin+ CD8+ T cells** 是 **免疫杀伤能力** 的关键功能指标。

|群体|免疫学意义|
|---|---|
|Perforin+ CD8+ T cells|具备活跃细胞毒作用，杀伤病毒或肿瘤|
|Perforin– CD8+ T cells|初始或调节状态，杀伤效应较弱|

该亚群是肿瘤免疫治疗、感染控制、疫苗研究和免疫衰老研究中的核心 readout。

🔬 <font color="#de7802">为什么使用 Rectangle Gate？</font>

|门类型|适用原因|
|---|---|
|Rectangle Gate|适合单参数 cutoff、快速明确阳性群体分离|
|Polygon Gate|更适用于形状复杂的分布|
|Range Gate（直方图）|用于单维分布阈值更直观的情况|

在 Perforin 这种 **单维表达阈值明显** 的功能标志物中，矩形门能够快速定义 **阳性（Perf+）** 区域。

#### 使用 T 按钮修改数据缩放与可视化显示

在某些情况下，由于流式细胞数据文件的类型不同，或采集软件设定的参数缩放方式不同，数据在图形窗口中的初始显示可能无法理想地呈现完整的事件分布。此时，可以使用坐标轴参数标签旁的 **T 按钮**轻松更改参数缩放方式，以优化数据可视化效果。

下面，让我们调整 **Perforin 参数的显示方式**，并探索 **双指数（Biexponential，Biex）转换函数** 中的可用缩放选项。

> 💡<font color="#de7802">注意：</font>  
> **双指数变换**会在**零点附近采用线性显示**，而在远离零值的区域使用**对数显示**。这种方式通常用于优化补偿后数据中出现的 **负值或低表达信号** 的展示，使弱阳性群体更容易区分。

📌 <font color="#de7802">补充说明 — 为什么需要 Transformation？</font>

流式数据常见的数值区间可能跨越多个数量级，并且在多色补偿后会产生 **负值事件**。  
如果直接使用线性（Linear）或对数（Log）方式显示：
- Linear 可能压缩低表达区域，使阴阳群体难以区分
- Log 在零点附近失真，无法处理负值

因此，**Logicle / Biexponential 变换** 是现代多色流式分析的最佳选择。

🔬 <font color="#de7802">为什么对 Perforin 数据使用双指数？</font>

|原因|说明|
|---|---|
|Perforin 表达分布可能包含弱表达和拖尾信号|需要拉开低强度信号结构|
|补偿后可能存在负值|logicle 可提供可读可解释的视图|
|识别 Perf+ vs Perf− 阴阳阈值|决定 gating precision 与统计准确性|

#### 操作练习：使用 T 按钮调整图形缩放与显示效果

1. **点击 X 轴 Perforin 参数标签旁的 T 按钮，并选择 “Customize Axis”**。  
    将打开 **Transformation（变换设置）窗口**，其中以直方图方式显示 Perforin 参数的分布情况。

![[FlowJo基础教程（二）-20251208-1.png]]

2. 在 **Scale（缩放模式）** 设置下，你会看到当前缩放模式已默认设置为 **Biex（双指数变换）**。  
    在保持 Biex 选中的状态下，你可以：
    - 使用 X 轴右侧的 `- / +` 按钮 **修改正向最大显示范围**
    - 使用 **Extra Neg Decades** 滑块 **增加或减少额外负值范围**
    - 使用 **Width Basis** 滑块 **调节零点附近的数据压缩程度**
3. 在 **Extra Neg Decades** 调节框中，将滑块向左移动。  
    这会将数据整体向左压缩，减少负值区间显示空间。  
    尝试将其设置为 **0**。
4. 在 **Width Basis** 调节框中移动滑块，你会看到：
    - **向右移动**滑块，会使零点附近的数据更**压缩紧凑**
    - **向左移动**滑块，会使零区附近的数据更**展开分散**  
        将 **Width Basis** 重新设置为 **1（−10）**。
5. 在右侧参数列表中，选中所有 **以 Comp- 开头的参数**。
6. 点击 **Apply（应用）**，将变换设置应用到所有补偿后的荧光通道。

![[FlowJo基础教程（二）-20251208-2.png]]

Transformation 设置窗口关闭后，所有被选中的参数都会应用刚才调整的缩放变化。在这个案例中，我们通过将 **Extra Neg Decades（额外负值区间）** 从 **0.8 调整为 0**，去除了在低位（负值）区域的一些多余空白显示空间，同时保持：
- **Maximum Range（最大显示范围）** 不变
- **Width Basis（零点偏压压缩参数）** 不变

经过这样的调整，可以为 **Perforin 表达分布图（Perforin expression profile）** 提供 **更清晰、更紧凑的视觉呈现空间**，使数据结构与群体边界更加直观易读。

此外，

> **每个测量参数都可以独立调整缩放方式，以增强事件分布显示的可读性和可解释性。**

📌<font color="#de7802">补充说明 — Transformation 不影响原始数据</font>

需要特别强调的是：**Transformation（数据变换）不会改变原始数据本身**。它只改变数据在图形中的视觉呈现方式，信号如何被绘制和显示。它**不会改变**原始采集的荧光强度值，后续统计结果（如 MFI、中位数、百分比），生物学意义或定量分析结果。

### 将门控层级应用于分组样本

现在，我们已经在一个样本上建立了完整的 **门控层级结构**。接下来，我们希望将这些门控应用到所有使用相同染色面板的样本上。为此，可以在 FlowJo Workspace 的 **分组面板** 中，将该门控层级结构应用于一个样本组。

#### 操作练习：应用门控结构到分组样本

点击 **Workspace** 窗口，你会看到在图形窗口中创建的门控名称现在在该样本下方呈缩进显示。这些门名称目前是 **黑色**，表示它们仅关联到当前这一单独的样本。

将门控应用到一个 Group 的步骤：
1. 在 Groups 面板中，选择 / 高亮 **TQC Basic Tutorial Data**（该组应包含全部 8 个样本）
2. 在样本面板中，选中当前样本下所有门控名称（gates）
3. 右键点击（或 Control-click）任意一个已选项目，选择：**Copy analysis to group（复制分析到分组）**

![[FlowJo基础教程（二）-20251208-3.png]]

完成后，FlowJo 会将整个 gating tree 应用到组内所有样本。你会发现：**门控现在出现在每个样本下面**，**也显示在分组下方**，**门颜色从黑色变为该组的颜色**，表示门控已经批量应用成功。

![[FlowJo基础教程（二）-20251208-4.png]]

### 修改组级门控 / Group-owned Gates

当门控结构被应用到一个组后，所有门控会变为该组的颜色，表示它们是 **Group-owned gates（组级门控）**，即在组内样本之间保持完全一致。然而，你仍然可以仅在个别样本上修改其中某个门控。

#### 操作练习：修改单个样本的组级门控

1. 在 Workspace 中，在组级 gating tree 内，**双击 Q1 CD4–, CD8+** 群体节点  
    打开对应的图形窗口，显示 **Perforin vs CD8** 参数分布图。
2. 点击 **Perf+ 矩形门** 以选中它，然后按住鼠标拖动该门到略微不同的位置。你会看到，Workspace 中 gating tree 内该门的节点颜色，从组颜色变为 **黑色**。
    📌 **黑色表示该门只属于当前样本，不再与组内其他门控相同**，即不再为 group-owned gate。

![[FlowJo基础教程（二）-20251208-5.png]]

3. 若希望将这个修改后的门控更新到组内所有样本，执行以下操作：
    - **选中该 gating group（分组）**
    - **仅选中黑色的 gate name（代表该门为当前独特门）**  
        （提示：若组内其他门控仍高亮，先点击其他区域取消选择，然后再单独选择黑色 gate）
    - 右键点击并选择 **Copy analysis to group**
    - 弹框提示：  
        **“Parent population already has a gate with the same name—Replace it?”**  
        点击 **Yes**
    完成后，修改后的 Perf+ gate 会重新应用于组内所有样本，并恢复为组颜色，表示门控结构再次与组同步。

![[FlowJo基础教程（二）-20251208-6.png]]

> ⭐<font color="#de7802">总结：</font>
> 
> 黑色表示 sample-specific gate，彩色表示 group-owned gate。  
> Copy analysis to group = 标准化、可重复、可比较的 gating 结构。

上述步骤说明了如何在修改单个样本的门控后，将该变化更新至整个组的门控结构。然而，在某些情况下，你可能希望 **组级门控始终保持同步**，也就是说：

> **当对任何一个 group-owned gate 进行修改时，这一改动会自动同步到组内所有样本**。无需再次执行“Copy analysis to group”流程。

这种自动同步方式可以避免重复操作，提高分析效率，并确保所有样本实时保持一致的门控结构，特别适合：多样本批次分析（如临床队列）、多时间点纵向分析、大 panel 多通道复杂门控策略、需要严格保证可重复性和一致性的发表级数据等。

要启用 group-owned gate 的同步功能：

#### 操作练习：同步组级门控

1. 在 **分组面板** 中，**双击** 目标 gating group 的名称  
    （例如：**TQC Basic Tutorial Data**）以打开 **Modify Group（修改组设置）** 窗口。

![[FlowJo基础教程（二）-20251208-7.png]]

2. 勾选 **Synchronized（同步）** 选项框。
3. 点击 **Apply Changes（应用修改）**。

![[FlowJo基础教程（二）-20251208-8.png]]

4. 关闭 Modify Group 窗口。  
    现在，该组的门控已处于 **同步模式**：当你修改任何一个 **group-owned gate** 时，该改变将 **自动同步** 到该组中的所有样本，无需再手动执行 “Copy analysis to group”。

目前我们已经完成了门控操作，因此现在可以关闭所有已打开的图形窗口，让工作区更加整洁，便于继续后续分析。

#### 操作练习：关闭图形窗口

1. **点击任意一个 图形窗口**，将其激活（选中）。
2. 若只想关闭该单独的图形窗口，点击窗口顶部的 **Close（关闭）按钮**。
3. 若希望一次关闭所有已打开的图形窗口，可使用快捷键：

|操作系统|快捷键|
|---|---|
|**Mac**|**Shift + Command + W**|
|**Windows / PC**|**Shift + Ctrl + W**|
