在共聚焦显微镜和活细胞成像系统高度普及的今天，我们每天都会产生大量三维和时间序列数据。然而，真正决定数据价值的，并不是“拍到了什么”，而是**如何展示它、解读它。**

很多科研工作者习惯于简单地做一个最大强度投影，然后直接用于汇报或论文图。但事实上，三维数据远比一张二维图复杂。不同的可视化方式，会直接影响我们对结构关系、空间分布甚至共定位结果的判断。

在这篇文章中，我将系统梳理 Fiji 中最常用的三维可视化方法，包括：
- Z Projection（Z轴投影）
- Orthogonal Views（正交视图）
- Reslice / Orthogonal Stack（正交重建）
- Slice Montage（切片拼图）
- 3D Project（基础三维体渲染）

不仅讲操作步骤，更讲原理、适用场景和常见误区。帮助你真正理解三维数据，而不是仅仅“生成一张图”。

## 三维数据的可视化

### Z轴投影

Z 投影（Z Projection）是将一个Z-stack中的多个Z层图像整合为一张二维图像的过程。其核心思想是：在每一个 (x, y) 位置上，根据设定的算法，从所有Z层中选取一个代表性像素值，生成最终图像。最常用的是：Maximum Intensity Projection（最大强度投影），该方法会在每一个 (x, y) 坐标上，从所有Z层中选取**强度值最高的像素**，将其投射到最终图像。

在荧光显微成像中，由于信号往往是亮结构（如荧光标记的细胞器、蛋白等），最大强度投影可以最大程度保留亮信号，因此应用最为广泛。

Fiji 中还提供以下几种投影算法，每种都有适用场景：
- **Average（平均值投影）**  适用于信号较均匀的情况，可降低随机噪声。
- **Minimum（最小值投影）**  在某些背景分析中有用途。
- **Sum（求和投影）**  常用于定量分析（例如总荧光强度评估）。
- **Standard Deviation（标准差投影）**  可突出变化明显的结构。
- **Median（中值投影）**  有助于减少离群噪声。

但在常规荧光图像展示中，**最大强度投影是最常用也是最直观的方法**。

##### 1. 打开示例数据

导入图像文件，本例文件是一个典型的Z-stack数据。

##### 2. 进行Z投影

菜单路径：`Image → Stacks → Z Project…`（或点击 Fiji 工具栏上的 “Stk” 按钮）。在弹出的对话框中：Projection Type 选择 **Max Intensity**，点击 OK。

![[三维数据与动态数据的可视化-20260211-2.png]]

##### 3. 观察结果

生成的图像会在每个 (x, y) 位置上显示沿Z轴方向的最亮像素。需要注意的是：如果原始数据包含很多Z层，所有层都参与投影时，可能会出现图像过于饱和、信号叠加严重、结构变得杂乱等问题，这是因为不同深度的结构被全部叠加到了同一平面。

为了得到更清晰的图像，可以限制参与投影的Z层范围，例如本例中设置参数如下：
- Start slice：5
- Stop slice：20

重新生成投影图像。此时图像更干净、结构更清晰、背景干扰减少。

### 正交投影（Orthogonal Projection）

正交投影（Orthogonal Projection）是将三维图像堆栈（Z-stack）从侧面进行观察的一种方式。  
除了常规的 XY 平面视图，我们还可以在：**XZ 平面**或**YZ 平面**上查看图像。

这种视图能够直观显示样本在 **Z 轴方向上的深度信息**，有助于判断结构在三维空间中的位置关系。例如：
- 某个荧光信号是否位于细胞顶部或底部？
- 两个结构是否真正共定位，还是仅在二维投影中看起来重叠？
- 样本是否存在Z轴漂移或厚度不均？

相比Z投影（Z Projection）将所有信息压缩到一个平面，正交视图能够“逐层”观察深度结构，因此在三维数据检查和质量控制中非常重要。

#### 操作步骤

##### 1. 打开示例数据

导入图像文件，本例中图像文件与上一部分图像文件相同。然后进入菜单：`Image → Stacks → Orthogonal Views`

##### 2. 界面说明

执行命令后，会出现两个新窗口：
- 右侧窗口：显示 **YZ 视图**
- 下方窗口：显示 **XZ 视图**

也就是说此时界面包含三个视图：原始 XY 视图（俯视图）、XZ 侧视图以及YZ 侧视图。

![[三维数据与动态数据的可视化-20260211-7.png]]

##### 3. 如何切换观察位置

在原始 XY 图像中，会看到一个 **黄色十字光标**。移动这个十字光标：
- 水平方向移动 → 改变 YZ 视图
- 垂直方向移动 → 改变 XZ 视图

本质上，你是在选择一个固定的 X 坐标（查看 YZ 截面）或固定的 Y 坐标（查看 XZ 截面）。这相当于在三维数据中“切开”一个侧面来观察。

#### 正交视图 vs Z 投影

| 方法               | 是否压缩Z信息 | 是否保留深度信息 | 适用场景     |
| ---------------- | ------- | -------- | -------- |
| Z Projection     | 是       | 否        | 快速展示整体结构 |
| Orthogonal Views | 否       | 是        | 分析三维空间关系 |

### 生成正交切片堆栈（Orthogonal Stack / Reslice Stack）

在前一节中我们使用了 **Orthogonal Views** 来查看 XZ 和 YZ 平面。但这种方式存在两个限制：
- 一次只能查看一个正交切面
- 视图中带有十字参考线，不适合直接用于展示或输出

在实际分析中，尤其是需要展示连续侧视结构、制作侧视方向的时间序列、对Z轴结构进行定量分析。更合适的方法是将图像堆栈沿新的轴向重新切片，生成一个真正的“正交方向堆栈”。本质上，这是将原始 Z-stack 在空间中重新排列，使原本的 Z 方向变为新的 XY 方向。

#### 操作步骤

##### 1️⃣ 打开示例数据

导入图像文件，本例中图像文件与上一部分图像文件相同。然后进入菜单：`Image → Stacks → Reslice [ / ]`

##### 2️⃣ Reslice 参数设置

弹出的对话框允许你设置以下内容：

🔹 切片方向（Start at）

可选择：
- Top（从上往下）
- Bottom（从下往上）
- Left
- Right

这决定了新堆栈生成的方向，即你希望沿哪个轴重新构建图像。

🔹 Output Spacing（切片间距）

该参数决定生成的新堆栈中，相邻切片之间的间距。
- 如果原始数据已经正确校准，通常**无需填写数值**
- 如果未校准，但你知道Z轴步长（例如 1 µm），可以在此输入

⚠️ 注意：这里设置的是 **Z轴间距（z spacing）**，不是 XY 像素尺寸。很多初学者容易混淆这两者。

🔹 Avoid Interpolation（避免插值）

勾选该选项意味着：不进行插值计算，不人为增加或重建像素信息，保持原始数据的真实性。但需要注意：如果原始数据的Z步长远大于XY分辨率，生成的新堆栈可能会显得被“压缩”或“拉伸”，结构比例可能失真。

如果不勾选：Fiji 会进行插值计算，图像看起来更平滑但像素信息已被数学重建。

![[三维数据与动态数据的可视化-20260211-8.png]]

##### 3️⃣ 生成正交堆栈

点击 OK 后，Fiji 会生成一个新的堆栈：每一层代表一个正交切面，相当于连续的 XZ 或 YZ 切片。

这个新堆栈可以像普通Z-stack一样操作：
- 制作电影（File → Save As → AVI）
- 生成 Montage
- 做 ROI 分析
- 再进行 Z Projection

![[三维数据与动态数据的可视化-20260211-9.png]]

### 切片拼图（Slice Montage）

Slice Montage（切片拼图）可以将一个共聚焦Z-stack中的所有切片，或选定的一部分切片，排列在同一张图像中进行展示。这种方式适用于展示整个Z轴扫描范围、比较不同深度的结构变化、快速评估信号在样本中的分布等。

同样的方法也可以用于时间序列数据（Time Stack），将不同时间点排列在同一张图中，直观展示动态变化。

与Z投影不同，Montage不会压缩Z信息，而是保留每一层的独立结构，因此更适合展示三维数据的“分层变化”。

#### 操作步骤

##### 1️⃣ 打开示例数据

导入图像文件，本例中图像文件与上一部分图像文件相同。然后进入菜单：`Image → Stacks → Make Montage…`

##### 2️⃣ 参数设置说明

弹出的 Make Montage 窗口允许自定义拼图布局。默认参数通常如下（具体数值可能随数据变化）：

![[三维数据与动态数据的可视化-20260211-10.png]]

🔹 Columns（列数）与 Rows（行数）

决定拼图的排布方式。例如：
- 5 Columns × 5 Rows → 每页显示 25 张切片
- 10 Columns × 3 Rows → 横向排列更紧凑

⚠️ 注意：这些参数**不会自动与数据切片数量匹配**。  如果设置不合理，可能出现：切片显示不完整、有空白区域、部分数据未被展示等，因此在设置前建议确认切片总数。

🔹 Scale Factor（缩放比例）

表示每一张切片在拼图中的缩放倍数。
- 1 = 保持原始分辨率
- 0.5 = 缩小为原来的一半
- 0.25 = 进一步缩小

✨ 建议：如果图像数量不多，优先设为 1。如图像过大导致文件尺寸过高，再后期统一缩放，提前缩小会降低可读性和清晰度。

🔹 Increment（间隔）

决定每隔多少张切片选取一张。
- 1 = 使用所有切片
- 2 = 每隔一张

在Z层很多的情况下（例如 80–100 层）：
- 使用 Increment > 1 可以减少拼图拥挤程度
- 有助于突出整体趋势

🔹 Border Width（边框宽度）

设置每个小图之间的边框线宽：
- 0 = 无边框
- 1 或更高 = 添加分隔线

在科研图制作中：若用于论文图，通常设置 0 或 1，过粗的边框会干扰视觉效果。

##### 3️⃣ 使用默认参数生成拼图

保持默认设置点击 OK。

![[三维数据与动态数据的可视化-20260211-11.png]]

生成的拼图可能会出现以下问题：图像过多，显得杂乱；每个切片分辨率较低，难以辨认每一层对应的Z位置。这在层数较多的Z-stack中尤为明显。

##### 4️⃣ 优化参数示例

可以尝试如下思路进行改进：
- 减少显示切片数量（增加 Increment）
- 合理设置行列布局
- 保持 Scale Factor = 1
- Border Width = 0 或 1

![[三维数据与动态数据的可视化-20260211-12.png]]

优化后的拼图结构更清晰，视觉更有层次，更容易观察信号在Z轴上的变化趋势。

![[三维数据与动态数据的可视化-20260211-13.png]]

### 基础三维体渲染（3D Volume – Simple）

在 Fiji 中，可通过多种方式对三维数据进行可视化。本节介绍的是最基础、最直观的三维体投影方法 -- **3D Project**。

与前面介绍的Z Projection（二维压缩）、Orthogonal Views（侧视切面）、Reslice（重建正交堆栈）不同，3D Project 会对整个 Z-stack 进行三维体重建，并生成一个可旋转的体投影视图。这种方法更接近“体渲染（volume rendering）”的概念。

需要注意：这属于基础级体渲染方式，高级三维可视化通常使用 Fiji 的 3D Viewer 插件或专门的可视化软件（如 Imaris、Arivis 等）。

#### 操作步骤

##### 1️⃣ 打开示例数据

导入图像文件，本例中图像文件与上一部分图像文件相同。

##### 2️⃣ 执行 3D Project

进入菜单：`Image → Stacks → 3D Project…`，保持默认参数，点击 OK。

![[三维数据与动态数据的可视化-20260211-14.png]]

##### 3️⃣ 观察生成结果

生成的是一个新的“旋转堆栈”。在图像底部会看到一个类似普通堆栈的滑块。但当你拖动滑块时，图像不会切换 Z 层，而是围绕某个轴（默认 Y 轴）旋转，这相当于生成了一组不同角度的二维投影图像。

![[三维数据与动态数据的可视化-20260211-15.png]]

当你将视角转到接近“侧面”时，可能会看到明显的层状线条。原因是：原始Z轴采样是离散的，Z步长通常大于XY分辨率，中间缺少连续体素信息。

如果未进行插值（Interpolation），系统只是按原始层面进行堆叠，因此会看到分层感。

##### 4️⃣ 使用 Interpolate 解决层状问题

重新运行：`Image → Stacks → 3D Project…`

这次勾选：✔ Interpolate

插值的作用是：在Z层之间计算中间体素值，生成更平滑的体结构，减少明显的“层线”。但需要理解：插值本质上是数学重建，而不是新增真实采集数据。

![[三维数据与动态数据的可视化-20260211-16.png]]

##### 5️⃣ 尝试不同参数

在 3D Project 对话框中，可以调整：

🔹 Axis of rotation （旋转轴）：X axis、Y axis、Z axis。不同轴会产生不同的旋转效果。

🔹 Initial Angle（旋转角度）

控制每一步旋转的角度间隔。例如：
- 10° → 生成36帧
- 5° → 生成72帧（更平滑，但数据量更大）

🔹 Projection Method（投影方式）

可选择不同的投影算法，例如：Brightest point（类似最大强度投影）、Nearest point、Mean value，不同算法会影响体结构的视觉表现。
