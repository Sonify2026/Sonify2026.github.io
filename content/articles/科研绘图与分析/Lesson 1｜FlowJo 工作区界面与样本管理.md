在流式细胞数据分析中，**FlowJo 工作区窗口**是整个分析流程的起点，也是建立门控策略、组织样本结构和进行数据可视化的核心指挥中心。无论你是刚刚接触流式细胞术的新手，还是希望提升分析效率和标准化流程的科研人员，理解 **工作区窗口的结构与关键组成部分**，将帮助你在后续分析中更加高效、稳定地处理数据。

本期内容将带你系统认识FlowJo的工作区窗口及其关键功能模块，为后续门控（Gating）、补偿（Compensation）、统计输出批处理（Batch）等深入内容做好准备。

### 工作区窗口的组成结构

当你第一次打开 **FlowJo** 时，会进入 **Workspace（工作区）** 窗口，它是进行流式数据分析的起点，也是所有分析操作的核心界面。  
该窗口自上而下通常被分为 **三个水平区域**：

1. **功能区工具栏** —— 位于窗口顶部，包含各种操作按钮，用于执行分析任务和调用功能，例如：
    - 导入数据
    - 创建分组（Groups）
    - 自动补偿（Compensation）
    - 创建布局与统计表（Layouts / Tables）

![[FlowJo基础教程（一）-20251205-1.png]]

2. **Groups（分组区域）** —— 位于窗口中部，用于组织样本数据。用户可以手动创建组、自动分配样本，或根据关键词进行分组管理。

![[FlowJo基础教程（一）-20251205-2.png]]

3. **Samples（样本区域）** —— 位于窗口底部，是最大的数据展示区，用于显示导入的所有 FCS 样本及其相关信息。  
    当工作区尚未导入数据时，该区域会显示提示语：**“Drag Samples Here”（将样本拖拽到此处）**。

![[FlowJo基础教程（一）-20251205-3.png]]

### 任务栏与功能区工具栏

在 FlowJo 工作区窗口的最左上角，是 **任务栏**。任务栏包含一排静态按钮，最左侧为 **FlowJo 金字塔图标按钮**，其右侧依次是 **前进与后退箭头** 等操作按钮。这些按钮执行工作区中的主要功能，例如：
- **添加样本（Add Samples）**
- **创建分组（New Group）**
- **打开 Layout Editor（布局编辑器）**
- **打开 Table Editor（表格编辑器）**

![[FlowJo基础教程（一）-20251205-4.png]]

在任务栏下方是 **功能区**，包含六个标签页：

**FlowJo | File | Edit | Workspace | Tools | Configure**

![[FlowJo基础教程（一）-20251205-5.png]]

点击不同的标签，可以访问相应的一组操作按钮。每个标签页进一步划分为若干 **工具带**，每个工具带底部显示其名称。  
例如，在 **FlowJo** 标签页中包含以下工具带：
- **Navigate（导航）**
- **Experiment（实验设置）**
- **Biology（生物学功能相关分析）**
- **Help（帮助）**

当鼠标悬停在按钮上时，会弹出 **工具提**，提供该功能的说明以及快捷键。

![[FlowJo基础教程（一）-20251205-6.png]]

#### 操作练习：向工作区添加样本

下面开始在新的 FlowJo 工作区中添加样本数据。

##### 方法一：拖拽导入

1. 找到软件提供的练习文件，即 **TQC Basic Tutorial Data** 文件夹。
2. 将整个 **TQC Basic Tutorial Data** 文件夹直接拖拽到 **样本区域** 中。

完成后：
- 样本文件会被加载到 FlowJo 工作区，并自动归入一个名为 **TQC Basic Tutorial Data** 的新分组。
- 同时，这些样本也会出现在 **All Samples** 组中。
- 样本名称显示在 **样本区域** 的 **Name** 列下。

![[FlowJo基础教程（一）-20251205-21.png]]

##### 方法二：使用 Add Samples 按钮导入

你也可以通过 **Add Samples** 按钮手动加载样本数据。该按钮有两个位置：
- 任务栏
- FlowJo 标签页中导航工具带内

![[FlowJo基础教程（一）-20251205-8.png]]

操作步骤如下：
1. 点击 **Add Samples**。
2. 在文件浏览框中导航到 **TQC Basic Tutorial Data** 文件夹。
3. 选中该文件夹并点击 **Choose（选择）**。

完成后，样本同样会加载到工作区并出现在 **All Samples** 组中。  

> 💡<font color="#de7802">注意：</font>只有在选择包含样本文件的文件夹层级导入时，FlowJo 才会自动创建与文件夹同名的分组。

### 分组面板

位于 FlowJo 工作区窗口中部的 **分组面板**，默认包含两个预设分组：
- **All Samples（全部样本）**：包含工作区内导入的所有数据文件。
- **Compensation（补偿组）**：自动收纳文件名中包含 **“comp”** 或 **“unstained”** 的样本，这些样本通常用于荧光补偿计算。

**分组** 的作用是帮助你对样本进行组织，使你能够在工作区中针对特定样本子集执行分析任务。

根据实验设计合理使用分组，你可以：
- **将实验完全染色样本（all-stain samples）与单染补偿管（single-stain compensation controls）区分开来**
- **根据样本文件关键字（metadata）进行分类**
    - 例如患者编号、抗体面板、刺激条件、采集时间点等
- **对使用相同染色面板的样本统一应用一致的门控策略（gating structure）**
- **创建特定分组的可视化图像报告与统计结果表**

#### 操作练习：创建新的分组

为了进一步理解分组功能，我们来手动创建一个新组。

**步骤如下：**
1. 在 **任务栏** 或 **FlowJo** 标签页中 **导航** 工具带内，点击 **Create Group（创建分组）**。

![[FlowJo基础教程（一）-20251205-9.png]]

2. 在窗口左上方的文本输入框中输入分组名称，例如：  
    **“My Group”**（或根据实验命名，例如 _DrugA 10µM_、_Day3_、_TIL_CD8_ 等）。
3. 在窗口右下角点击 **Create Group（创建组）** 完成分组创建。

![[FlowJo基础教程（一）-20251205-10.png]]

4. **点击 Close（关闭）按钮** 以关闭对话框。  
	此时，你会注意到在 **分组面板** 中出现了一行新的分组名称。由于目前还没有将样本添加到该分组中，因此在下面的 **样本区域** 中不会显示任何样本名称。

![[FlowJo基础教程（一）-20251205-12.png]]

#### 操作练习：拖拽样本至分组

要将样本手动加入新建的分组，请按以下步骤操作：
1. 点击任意包含样本的分组使其高亮显示，例如 **All Samples** 或 **TQC Basic Tutorial Data**。  
    在 **样本区域** 中选中前四个样本（它们的文件名中均包含 **LD1**）。
2. 将选中的样本拖拽到 **My Group** 分组名称上并释放。  
    此时，**My Group** 中即包含了这些样本。

![[FlowJo基础教程（一）-20251205-13.png]]

| 选中方式  | 操作                                |

| 连续选择  | Shift + 点击                        |
| 非连续选择 | Ctrl（Windows） / Command（Mac） + 点击 |

> 💡注意：**同一个样本可以同时存在于多个分组中**。  
> （例如，你刚刚添加到新建分组中的样本，依然保留在 **All Samples** 和 **TQC Basic Tutorial Data** 分组中。）

<font color="#de7802">要从某个分组中移除样本：</font>
1. 选中你希望移除样本的目标分组。
2. 在 **样本区域** 中选中需要移除的样本。
3. 在键盘上按 **Delete** 键。
4. 在弹出的提示框 **“Are you sure you want to remove sample(s)?”（确认移除样本？）** 中点击 **Yes（是）**。

![[FlowJo基础教程（一）-20251205-14.png]]

><font color="#de7802"> FlowJo 中移除样本的行为特点：</font>
> - **删除样本仅是从该分组移除，不会删除其原始 FCS 文件，也不会从其他分组中移除**
> - **移除样本不会影响 Raw Data 或 gating 结果**，只是撤销其在某个分析组中的显示与参与

### 样本面板

工作区窗口的底部区域是 **样本面板**，用于显示当前在 **分组面板** 中选定分组内的所有流式细胞术数据文件列表。

**Samples pane 默认展示三列信息：**
1. **Name（名称）**  
    显示样本文件名，对应 FCS 标准中的 **$FIL 关键字属性**。
2. **Statistic（统计）**  
    显示应用分析后得到的统计结果，例如百分比、细胞计数、平均荧光强度（MFI）等。
3. **#Cells（细胞事件数）**  
    显示样本文件中记录的事件数量，当应用门控策略后，将显示对应门内的细胞数。

最初加载样本时，样本会按文件名称的字母顺序排列。

![[FlowJo基础教程（一）-20251205-15.png]]

#### 样本标识徽章：

在样本名称左侧，会显示一系列图标，称为 **样本徽章（sample badges）**，用于快速识别样本状态、分析结构或数据处理信息（例如补偿状态、门控结构、统计结果等）。  


![[FlowJo基础教程（一）-20251205-16.png]]

##### 补偿矩阵徽章 — 方形图标

在样本名称左侧最靠近名称的位置，是 **补偿矩阵徽章（Compensation badge）** 的方形图标。该图标有两种显示形式：
1. **空心方框**：表示该样本尚未应用补偿矩阵（no compensation applied）。
2. **填充网格方框**：表示样本已应用补偿矩阵（compensation applied）。

在本教程示例数据中，方框为 **填充状态**，说明补偿已经在流式细胞仪采集过程中完成，因此这些数据文件进入 FlowJo 时已包含补偿矩阵。

双击该补偿矩阵图标，可以打开一个窗口，查看与该样本关联的补偿矩阵，并预览补偿对数据形态的影响。该窗口的深入使用将在 **后续推文** 中详细介绍。

![[FlowJo基础教程（一）-20251205-18.png]]

> 📌<font color="#de7802">补充说明  — 流式补偿（Compensation）为何重要？</font>
> 
> 在多色流式细胞术中，由于不同荧光染料的发射谱线之间有重叠，导致某个通道的真实信号会“溢出（spillover）”到其他检测通道。**补偿（Compensation）** 通过计算并减去溢出量，最大化区分不同荧光信号，使数据更准确可靠。

##### 样本质量徽章 — 圆形图标

第二个（中间位置）的徽章是 **样本质量标识（Sample Quality Badge）**，用于指示样本采集质量，并提供访问样本属性信息的入口。

**双击该圆形徽章** 将执行样本质量检查，用于评估**采集过程在时间维度上的稳定性**，包括所有荧光参数的信号变化情况。同时会打开 **Sample Properties（样本属性）** 窗口，其中包含：
- 样本的 **关键词属性（keyword attributes / metadata）**
- **采集所用流式细胞仪仪器设置（instrument settings）**
- **补偿信息（compensation）**

<font color="#de7802">颜色指示采集稳定性：</font>

|颜色|质量评价|可能含义|
|---|---|---|
|**蓝色**|质量良好|采集过程稳定可靠|
|**绿色 / 紫色**|可接受|可能存在轻微波动|
|**黄色 / 红色**|质量较差|存在采集堵塞、压力波动或流速异常|

如果徽章呈 **黄色或红色**，可能说明采样期间出现：
- **样本管堵塞**
- **事件流速波动**
- **压力稳定性差**
- **仪器流动室污染或气泡**

这些问题可能导致信号漂移（fluorescence drift）、事件丢失、或者门控群体变形，从而影响最终分析结果。

#### 操作练习： 检查样本质量并查看单个样本的属性

1. 在 **样本面板** 中，**双击圆形的 Sample Quality 徽章**。
2. 此时会弹出一个 **Sample Properties（样本属性）** 窗口，展示该样本的详细信息，同时在圆形徽章内会出现一个彩色标记点。

![[FlowJo基础教程（一）-20251205-17.png]]

若徽章显示为 **蓝色或绿色**，则说明样本在采集过程中 **稳定性良好**，没有明显信号漂移或采集堵塞问题。

#### 操作练习：对工作区中所有样本执行质量检查

你也可以对 **工作区中的全部样本** 进行一次批量的质量检查。
	在 **功能区工具栏** 中，点击 **Check Sample Quality（检查样本质量）** 按钮，该按钮位于 **FlowJo** 标签下的 **Cytometry** 工具带中。

![[FlowJo基础教程（一）-20251205-19.png]]

完成后，所有样本的 **圆形徽章** 中都会出现一个彩色点，用于表示样本采集过程中的质量和稳定性。

![[FlowJo基础教程（一）-20251205-20.png]]

#### 群体标记徽章 — 菱形图标

最左侧的徽章是 **Population Marker Badge（群体标记徽章）**，用于指示当前在 **Sample Preview（样本预览）** 或 **Graph window（图形窗口）** 中正在查看哪些样本或细胞群体。（该功能将在后续的推文中进一步展开。）

当你在 **样本面板** 中双击某个样本名称时，会打开一个 **Graph Window（图形窗口）** 并显示相应的散点图（dot plot）。此时，样本名称旁的 **菱形徽章将变为蓝色**，表示该样本正在图形窗口中展示。

<font color="#de7802">徽章颜色与样式说明：</font>

|徽章样式|状态含义|实际意义|
|---|---|---|
|**实心蓝色菱形**|Graph Window 已选中（active）|当前正在操作和查看的窗口|
|**空心蓝色菱形**|样本窗口已打开但非当前选中|样本仍在显示，但窗口位于后台|

> 📌<font color="#de7802">补充说明  — 群体标记徽章的作用</font>
> 
> 在多样本对比分析中，特别是批量 gating 或布局作图时，同时查看和切换多个 Graph Window 是常见需求，该徽章能帮助你：
> - 快速识别哪些样本图像当前处于活动状态
> - 在多个打开的图像窗口中进行可视化比较和审阅
> - 避免误操作错误样本窗口
> - 进行 **overlay 叠加比较** 等深入分析（后续章节会讲解）
