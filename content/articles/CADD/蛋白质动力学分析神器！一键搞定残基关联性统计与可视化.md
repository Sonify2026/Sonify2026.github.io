残基关联性分析是描述分子内构象变化的一种有效方法。本期内容为大家分享如何使用Schrödinger结合Python轻松搞定蛋白质残基的关联性分析！

在蛋白质分子动力学模拟中，分析初始结构和最终结构的残基关联性变化是理解蛋白质动态行为的关键。本例中我们定义两个残基之间的距离小于4.5Å为残基发生相互作用的阈值，我们需要分析分子动力学的初始结构（0ns）和最终结构（100ns）之间的残基关联差异。即需要以下内容：

- 统计初始结构和最终结构中满足相互作用阈值（如 D<sub>ij</sub><4.5 Å）的残基对数目。
- 计算**关联相似度**（如 Jaccard 相似度、余弦相似度）和**衰减率**。
- 输出满足条件的残基对及其距离，便于进一步分析或可视化。

### 1. 残基相互作用分析

我们需要使用Schrödinger分析蛋白结构内残基之间的距离，在Maestro中导入蛋白结构，一次点击`TASKS - > Browse - > Structure Analysis - > Residue Distance Map `
打开`Residue Distance Map`窗口；
![[Pasted image 20250131103424.png]]
点击`Load`导入结构，这里我们选择通过两个残基之间**α碳的距离**来定义两个残基的距离，在`Plot`的下拉菜单中选择`C-alpha atoms`，在`Label axes with`的下拉菜单中选择`Residue Number`;

需要注意的是α碳是蛋白质骨架的核心原子，用它代表残基位置可以简化距离计算，**在某些情况下是合理的，但存在局限性**。实际应用中应视情况改进，如结合侧链重原子（如Cβ、Cγ等）或质心距离，更准确地反映残基间的空间关系。

### 2. 关联性统计分析

接下来我们使用Python来对数据处理分析，需要计算以下关键指标：

#### 关联相似度

##### ① Jaccard 相似度

Jaccard 相似度用于衡量初始结构和最终结构相互作用模式的相似性。

$$
\text{Jaccard 相似度} = \frac{|A_{\text{initial}} \cap A_{\text{final}}|}{|A_{\text{initial}} \cup A_{\text{final}}|}
$$

- **分子**：初始结构和最终结构中同时满足相互作用阈值（D<sub>ij</sub><4.5 Å）的残基对数目。
- **分母**：初始结构或最终结构中满足相互作用阈值的残基对数目。

##### ② 余弦相似度

余弦相似度用于量化残基运动的相关性。

$$
\text{余弦相似度} = \frac{\sum_{i,j} A_{\text{initial}, ij} \cdot A_{\text{final}, ij}}{\sqrt{\sum_{i,j} A_{\text{initial}, ij}^2} \cdot \sqrt{\sum_{i,j} A_{\text{final}, ij}^2}}
$$

- A<sub>initial</sub>,<sub>ij</sub>​：初始结构的相互作用矩阵。
- A<sub>final</sub>,<sub>ij</sub>​：最终结构的相互作用矩阵。

#### 衰减率

衰减率用于评估初始结构和最终结构中相互作用数目的变化。

$$
\text{衰减率} = 1 - \frac{N_{\text{final}}}{N_{\text{initial}}}
$$

- N<sub>initial</sub>​：初始结构中满足相互作用阈值的残基对数目。
- N<sub>final</sub>​：最终结构中满足相互作用阈值的残基对数目。

#### 公共关联的数目

公共关联的数目是指初始结构和最终结构中同时满足相互作用阈值的残基对数目。

$$
N_{\text{common}} = |A_{\text{initial}} \cap A_{\text{final}}|
$$
**代码实现：**

```python
import numpy as np  
import pandas as pd  
  
# 使用 pandas 读取 CSV 文件  
df_initial = pd.read_csv('initial_distance_matrix.csv', index_col=0)  
df_final = pd.read_csv('final_distance_matrix.csv', index_col=0)  
  
# 将 DataFrame 转换为 NumPy 数组  
D_initial = df_initial.to_numpy()  
D_final = df_final.to_numpy()  
  
# 定义相互作用阈值  
threshold = 4.5  # Å  
  
# 构建相互作用矩阵  
A_initial = (D_initial < threshold).astype(int)  
A_final = (D_final < threshold).astype(int)  
  
# 统计关联的残基数目（只统计上三角部分，不包括对角线）  
def count_interactions(interaction_matrix):  
    """  
    统计相互作用矩阵中满足条件的残基对数目（上三角部分，不包括对角线）。  
    :param interaction_matrix: 相互作用矩阵（NumPy 数组）  
    :return: 满足条件的残基对数目  
    """    count = 0  
    n = interaction_matrix.shape[0]  
    for i in range(n):  
        for j in range(i + 1, n):  # 只遍历上三角部分，跳过对角线  
            if interaction_matrix[i, j] == 1:  
                count += 1  
    return count  
  
N_initial = count_interactions(A_initial)  # 初始结构中关联的残基对数目  
N_final = count_interactions(A_final)      # 最终结构中关联的残基对数目  
  
# 统计公共关联的数目  
def count_common_interactions(initial_matrix, final_matrix):  
    """  
    统计初始结构和最终结构中同时满足相互作用阈值的残基对数目。  
    :param initial_matrix: 初始结构的相互作用矩阵  
    :param final_matrix: 最终结构的相互作用矩阵  
    :return: 公共关联的残基对数目  
    """    count = 0  
    n = initial_matrix.shape[0]  
    for i in range(n):  
        for j in range(i + 1, n):  # 只遍历上三角部分，跳过对角线  
            if initial_matrix[i, j] == 1 and final_matrix[i, j] == 1:  
                count += 1  
    return count  
  
N_common = count_common_interactions(A_initial, A_final)  # 公共关联的残基对数目  
  
# 计算 Jaccard 相似度  
intersection = N_common  
union = N_initial + N_final - N_common  
jaccard_similarity = intersection / union  
  
# 计算余弦相似度  
cosine_similarity = np.sum(A_initial * A_final) / (np.linalg.norm(A_initial) * np.linalg.norm(A_final))  
  
# 计算衰减率  
reduction_ratio = 1 - (N_final / N_initial)  
  
# 输出统计结果  
print(f"初始结构中关联的残基对数目: {N_initial}")  
print(f"最终结构中关联的残基对数目: {N_final}")  
print(f"公共关联的残基对数目: {N_common}")  
print(f"Jaccard 相似度: {jaccard_similarity:.4f}")  
print(f"余弦相似度: {cosine_similarity:.4f}")  
print(f"衰减率: {reduction_ratio:.4f}")  
  
# 将满足相互作用阈值的残基对及其距离输出到新文件  
def save_interactions_to_file(distance_matrix, index_labels, output_file):  
    """  
    将满足相互作用阈值的残基对及其距离保存到文件。  
    :param distance_matrix: 距离矩阵（NumPy 数组）  
    :param index_labels: 残基编号（DataFrame 的索引）  
    :param output_file: 输出文件名  
    """    with open(output_file, 'w') as f:  
        f.write("ResID1,ResID2,Distance\n")  # 写入标题行  
        n = distance_matrix.shape[0]  
        for i in range(n):  
            for j in range(i + 1, n):  # 只遍历上三角部分，跳过对角线  
                if distance_matrix[i, j] < threshold:  
                    f.write(f"{index_labels[i]},{index_labels[j]},{distance_matrix[i, j]:.2f}\n")  
  
# 保存初始结构和最终结构的相互作用数据  
save_interactions_to_file(D_initial, df_initial.index, 'initial_interactions.csv')  
save_interactions_to_file(D_final, df_final.index, 'final_interactions.csv')  
  
# 保存公共关联的残基对及其距离到新文件  
def save_common_interactions(initial_matrix, final_matrix, index_labels, output_file):  
    """  
    将初始结构和最终结构中同时满足相互作用阈值的残基对及其距离保存到文件。  
    :param initial_matrix: 初始结构的距离矩阵  
    :param final_matrix: 最终结构的距离矩阵  
    :param index_labels: 残基编号（DataFrame 的索引）  
    :param output_file: 输出文件名  
    """    with open(output_file, 'w') as f:  
        f.write("ResID1,ResID2,Distance_Initial,Distance_Final\n")  # 写入标题行  
        n = initial_matrix.shape[0]  
        for i in range(n):  
            for j in range(i + 1, n):  # 只遍历上三角部分，跳过对角线  
                if initial_matrix[i, j] < threshold and final_matrix[i, j] < threshold:  
                    f.write(f"{index_labels[i]},{index_labels[j]},{initial_matrix[i, j]:.2f},{final_matrix[i, j]:.2f}\n")  
  
# 保存公共关联的残基对  
save_common_interactions(D_initial, D_final, df_initial.index, 'common_interactions.csv')  
  
print("满足相互作用阈值的残基对已保存到 initial_interactions.csv 和 final_interactions.csv 文件中。")  
print("公共关联的残基对已保存到 common_interactions.csv 文件中。")
```
